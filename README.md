# WORLDS

An original open-world adventure project built with Godot 4, targeting Android first and PC later.

## Current milestone

The repository now contains the first Godot project scaffold and an early 3D world prototype:
- Procedurally generated rolling green terrain
- A winding river and a small forest
- A third-person player capsule and follow camera
- Basic keyboard movement and on-screen touch controls
- A lightweight mobile-oriented renderer configuration

This is an early prototype, not the complete game. Multiplayer, saving, survival systems, building, polished character art, and production assets are future milestones.

## Open the project

1. Install Godot 4.3 or a compatible Godot 4 release.
2. Download this repository as a ZIP or clone it.
3. In Godot, choose **Import** and select the folder containing `project.godot`.
4. Open `scenes/main.tscn` and press **Run Project**.

## Controls

- Keyboard: WASD to move, Space to jump.
- Touch: use the on-screen directional buttons and Jump button.

## Important

No Android APK has been built or tested yet. The project must be imported and tested in Godot first, then configured and exported for Android.
